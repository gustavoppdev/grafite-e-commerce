# Study scope: what this store deliberately does not have

This is a study project meant to be finished, so the domain is kept small on purpose. Payment is a simulated card form (validated, never sent to a provider, full card data never persisted); there are no coupons, calculated shipping, product variants, subcategories, multi-category products, product images (a neutral placeholder is shown instead), reviews, wishlists, guest checkout, customer account deletion, two-factor authentication, sales charts or Admin audit logs. These are not missing features to be "fixed": adding any of them is a scope change and should get its own ADR.
